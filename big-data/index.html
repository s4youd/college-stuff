The core definitionwhat “big data” actually means

Big Data is data that is large, rapidly growing and diverse enough to challenge traditional processing methods. The test bank adds the operational version: it is the analysis of datasets that are too large or too complex for traditional data-processing tools to handle.

It is not a single technology. It is a stack of answers to one failure: a single server with a fixed relational schema cannot store every format, ingest every speed, or scale past its own hardware. The answer is distributed storage + parallel processing + flexible models.

The subject travels one arc: define the data (Lecture 1) → learn from it (Lectures 2–4) → wire the ecosystem that moves and stores it (Lecture 5) → survive the exam (the Last Mile).

“A dataset does not become big when it grows up. It becomes big when your old machine files a complaint.”

Volume is only the symptom. The diagnosis is a fixed schema, a single box, and a clock that cannot wait.

— THE DATA JANITOR

◈
Why the old machine gives upRDBMS limits · single server · distributed systems

A relational database management system (RDBMS) is designed for structured data in rows and columns, with a fixed schema and SQL. That design is excellent for transactions and reporting — and it is exactly the wrong shape for raw text, video, logs and sensor streams that arrive every millisecond.

A single-server architecture puts every operation on one machine. Its limit is not a bug; it is physics: CPU, RAM, disk and network all have a ceiling. Distributed systems divide data across multiple servers and process it in parallel, so capacity grows by adding nodes (horizontal scaling) rather than buying a bigger box (vertical scaling).

QuestionRDBMS / single serverDistributed Big Data system
Data shapeFixed schema, rows and columnsStructured, semi-structured and unstructured
ScalingVertical — bigger machineHorizontal — more machines
ProcessingCentralised, often serialParallel across nodes
FailureOne machine, one point of failureReplication and fault tolerance
Best atTransactions, integrity, SQLVolume, variety, velocity, scale
“One machine can be brilliant. It still has one power cable.”

Scale out before you scale up — a rack has more room than a box.

— THE NIGHT SHIFT
لماذا تفشل الطرق التقليدية؟
نظام إدارة قواعد البيانات العلائقية (RDBMS) مصمم للبيانات المنظّمة في صفوف وأعمدة بمخطط ثابت ولغة SQL. هذا ممتاز للمعاملات والتقارير، لكنه الشكل الخطأ للنصوص الخام والفيديو والسجلات وتدفقات الحساسات التي تصل كل جزء من الثانية.
معمارية الخادم الواحد تضع كل العمليات على جهاز واحد، وحدودها ليست خطأً بل قيوداً مادية: المعالج والذاكرة والقرص والشبكة لها سقف. أما الأنظمة الموزعة فتقسم البيانات على عدة خوادم وتعالجها بالتوازي، فينمو القدرة بإضافة عقد (توسع أفقي) بدلاً من شراء جهاز أكبر (توسع رأسي).

Three data typesthe schema tells you which tool to use
TypeSchemaExamplesTypical tools
StructuredFixed, predefined: rows and columnsCustomer records, transactions, inventory tablesRDBMS, SQL, Hive
Semi-structuredFlexible, carried by tags, keys or attributesJSON, XML, email, logs, event payloadsNoSQL, document stores, Spark
UnstructuredNo predefined schemaText, images, video, audio, sensor streamsData lake, NLP, computer vision, Spark

Structured data is easy to query with standard SQL. Semi-structured data carries its schema inside the data — a JSON document tells you its own field names. Unstructured data needs specialised techniques: NLP for text and computer vision for images. Standard SQL alone cannot query raw video.

أنواع البيانات الثلاثة:
البيانات المنظّمة: مخطط ثابت مسبقاً في صفوف وأعمدة مثل سجلات العملاء والمعاملات، وتُستعلم بـSQL. والبيانات شبه المنظّمة: مخطط مرن يحمله الوسم أو المفتاح أو السمة مثل JSON وXML والسجلات والبريد، فكل مستند يشرح حقوله بنفسه. والبيانات غير المنظّمة: بلا مخطط مسبق مثل النصوص والصور والفيديو والصوت وتدفقات الحساسات، وتحتاج تقنيات متخصصة: معالجة اللغة الطبيعية للنصوص والرؤية الحاسوبية للصور. وSQL وحدها لا تستعلم فيديو خاماً.

The five Vsthree original + two added
VQuestion it asksOne example
VolumeHow much data is there?Petabytes of clickstream and transaction history.
VelocityHow fast does it arrive and need processing?Millions of sensor readings or card swipes per second.
VarietyHow many shapes does it take?Tables + JSON logs + video + free text in one pipeline.
VeracityCan we trust it?Missing values, duplicate records, noisy sensors, bias.
ValueDoes it change a decision?A fraud alert, a demand forecast, a saved cost.

The three original dimensions are volume, velocity and variety. The 5Vs framework adds veracity and value. Two impostors to reject in the exam: validation is a process, not a V; volatility is not one of the five in this course. Memorise the list and stop.

الأبعاد الخمسة:
الحجم (Volume): كم البيانات؟ السرعة (Velocity): كم تصل بسرعة وتحتاج معالجة؟ التنوع (Variety): كم شكل تأخذه؟ الموثوقية (Veracity): هل يمكن الوثوق بها؟ القيمة (Value): هل تغيّر قراراً؟
الأبعاد الأصلية ثلاثة: الحجم والسرعة والتنوع. ويضيف إطار الخمسة: الموثوقية والقيمة. وانتبه لمصيدتين: التحقق (Validation) عملية وليس بُعداً، والتقلب (Volatility) ليس أحد الأبعاد الخمسة في هذا المقرر. احفظ القائمة وتوقف.

Four analytics questionsthe ladder from “what” to “do this”
TypeQuestionOutputExample
DescriptiveWhat happened?Reports, dashboards, KPIsLast month’s sales by region.
DiagnosticWhy did it happen?Root cause, drill-down, correlationWhy returns rose in the north.
PredictiveWhat will happen?Forecast, probability, model scoreWhich customers will churn next quarter.
PrescriptiveWhat should we do?Recommendation, optimisation, actionOffer a discount to the 12% at risk.

The ladder is also a value ladder: each step is harder, needs more data and more trust, and answers a more expensive question. Descriptive explains the past; diagnostic explains causes; predictive estimates the future; prescriptive recommends an action.

أنواع التحليلات الأربعة:
الوصفي (Descriptive) يجيب: ماذا حدث؟ عبر التقارير ولوحات المؤشرات. والتشخيصي (Diagnostic) يجيب: لماذا حدث؟ عبر تحليل السبب الجذري والتعمق والارتباط. والتنبؤي (Predictive) يجيب: ماذا سيحدث؟ عبر النماذج والاحتمالات والتوقعات. والتوصوي (Prescriptive) يجيب: ماذا نفعل؟ عبر التوصيات والتحسين والمحاكاة.
كل درجة أصعب وتحتاج بيانات وثقة أكثر، وتجيب سؤالاً أغلى. الوصفي يشرح الماضي، والتشخيصي يشرح الأسباب، والتنبؤي يقدّر المستقبل، والتوصوي يوصي بفعل.

Data quality, labeling & metadatagarbage in, expensive garbage out

Data quality is the fitness of data for analysis. The usual dimensions are accuracy (correct), completeness (nothing essential missing), consistency (the same fact agrees across systems), timeliness (fresh enough), validity (within allowed rules) and uniqueness (no duplicates). Poor quality is one of the most common Big Data challenges: the model is only as good as the data it learns from.

Data labeling gives examples an annotation — a class, a price, a bounding box. It matters for supervised machine learning because the algorithm learns from annotated input–output examples. Metadata (data about data: source, schema, owner, timestamp) improves organisation, searchability and learning. Data prioritization and filtering removes irrelevant information, reducing storage and processing cost.

PracticeWhat it fixesExam phrase
Cleaning / wranglingErrors, missing values, inconsistent formats“Cleaning and organising data”
LabelingNo ground truth for supervised learning“Annotated examples for model training”
MetadataUnfindable, undocumented data“Organisation, searchability, learning”
FilteringIrrelevant data and wasted cost“Reduce storage and processing costs”
AccessibilityData locked away from the right people“Available to authorised users — not everyone”
جودة البيانات ووسمها والبيانات الوصفية:
جودة البيانات هي مدى صلاحيتها للتحليل: الدقة (صحيحة)، والاكتمال (لا ينقصها جوهري)، والاتساق (الحقيقة نفسها متفقة بين الأنظمة)، والتوقيت (حديثة بما يكفي)، والصلاحية (داخل القواعد)، والتفرد (بلا تكرار). وضعف الجودة من أشهر تحديات البيانات الضخمة: النموذج بجودة البيانات التي يتعلم منها.
ووسم البيانات يمنح الأمثلة تعليقاً — فئة أو سعراً أو إطاراً — وهو مهم للتعلّم المُوجَّه لأن الخوارزمية تتعلم من أمثلة مدخلات ومخرجات موسومة. والبيانات الوصفية (مصدر البيانات ومخططها ومالكها ووقتها) تحسّن التنظيم والبحث والتعلّم. وترتيب الأولويات والفلترة يحذف المعلومات غير ذات الصلة فيقلل تكلفة التخزين والمعالجة.
⌘
Security, backups & resilienceprotect it, copy it, test the copy
  • Encryption — protect data at rest and in transit.
  • Authentication — prove who the user is.
  • Authorization — decide what that user may do.
  • Continuous monitoring — detect misuse and anomalies.
  • Multi-location redundancy — keep copies in more than one place.
  • Offsite / geographic redundancy — survive a site-level disaster.
  • Tested backups — a backup you never restore is a hope, not a backup.

Data accessibility means the right people can reach the data — not that everyone has unrestricted access. Security and accessibility are balanced by authentication, authorization and auditing.

الأمن والنسخ الاحتياطي والمرونة:
التشفير يحمي البيانات المخزنة والمنقولة، والمصادقة تثبت هوية المستخدم، والتفويض يحدد ما يستطيع فعله، والمراقبة المستمرة تكشف إساءة الاستخدام والشذوذ. والتكرار متعدد المواقع يحفظ نسخاً في أكثر من مكان، والتكرار الجغرافي ينجّي من كارثة موقع كامل، والنسخة الاحتياطية المختبرة فقط هي نسخة حقيقية — ما لم تُستعد منها فأنت تأمل لا تحمي.
وإتاحة البيانات تعني وصول الأشخاص المصرح لهم، لا وصول الجميع بلا قيود. والتوازن بين الأمن والإتاحة يتم بالمصادقة والتفويض والتدقيق.

Exam trapthe definition, the five, and the clock

Big Data is not simply “any data that does not fit in a relational database”. That is a useful shorthand, but the lecture definition is about volume, growth, diversity and the limits of traditional methods. Write the full idea, then give the shorthand as an example.

The five Vs are Volume, Velocity, Variety, Veracity and Value. Validation is not a V. Volatility is not a V. If an option says “Validation” or “Volatility”, eliminate it before you read the rest.

Batch is not real-time. Batch processing runs on a schedule over stored data; stream processing acts on data as it arrives. A question that says “batch provides continuous real-time analysis” is false.

“Five Vs walk into a bar. The bouncer checks veracity at the door.”

Validation is a process, not a V. Volatility never made the guest list.

— PROFESSOR PORTAL

◈
Rules vs learningthe two ways to make a machine decide

Traditional programming gives the computer inputs and rules, and it produces outputs. Machine learning gives the computer inputs and desired outputs, and the algorithm discovers rules or patterns. That inversion is the whole idea.

Traditional: data + rules → answers→ ML: data + answers → rules

Use ML when the problem contains complex patterns that are difficult to specify as rules — recognising a face, predicting demand, detecting fraud. Prefer a simple, reliable rule-based system when one exists: it is cheaper, explainable and easier to debug. No data means no learning; errors with consequences mean you need validation, not blind trust.

“If a one-line rule already solves it, the neural network is an expensive way to agree with the rule.”

Use learning for patterns you cannot spell out, not for decisions you can.

— THE DATA JANITOR

Deep learning & the networklayers of learned representation

Deep learning is a specialised branch of machine learning that uses multilayered neural networks. It is not a database technique and not a rule engine. Each layer transforms the representation, so the network can learn features that nobody hand-coded.

  • Input layer — receives the data.
  • Hidden layers — learn patterns and representations.
  • Output layer — produces prediction probabilities or a learned representation.

Deep learning usually benefits from a large amount of data and suitable hardware (GPU/TPU). Its patterns are not always easily interpretable by humans. It is not automatically the right choice when errors are unacceptable, and a changing environment can break a model trained on yesterday’s distribution.

التعلّم العميق والشبكة العصبية:
التعلّم العميق فرع متخصص من تعلّم الآلة يستخدم شبكات عصبية متعددة الطبقات. ليس تقنية قواعد بيانات ولا محرك قواعد ثابتة. كل طبقة تحول التمثيل، فيتعلم النموذج خصائص لم يكتبها أحد يدوياً.
طبقة الإدخال تستقبل البيانات، والطبقات المخفية تتعلم الأنماط والتمثيلات، وطبقة الإخراج تنتج احتمالات التنبؤ أو تمثيلاً متعلماً. والتعلّم العميق يستفيد عادةً من بيانات كثيرة وعتاد مناسب (GPU/TPU)، وأنماطه ليست دائماً قابلة للتفسير البشري. وليس الخيار الأفضل تلقائياً عندما تكون الأخطاء غير مقبولة، والبيئة المتغيرة قد تكسر نموذجاً دُرّب على توزيع الأمس.

Overfitting & random seedsmemorise nothing · reproduce everything

Overfitting happens when a model memorises the training data instead of learning general patterns. Its training score looks excellent and its performance on unseen data collapses. The exam wording is exact: overfitting is not “failing to learn” — that is underfitting — and it is not “always producing identical predictions”.

A random seed makes a pseudorandom process reproducible. It does not remove randomness permanently; it makes the same sequence appear again. If both a global seed and an operation-level seed are set, TensorFlow uses both together to determine the random sequence. Shuffling the data also reduces the influence of the original row order during training.

Squeeze & expandremove or add a dimension of size one

tf.squeeze() removes dimensions whose size is 1. A tensor of shape [1, 224, 224, 3] becomes [224, 224, 3] — the classic batch-of-one image fix. tf.expand_dims() or tf.newaxis does the opposite: it inserts a new axis of size one.

OperationShape beforeShape after

Squeeze removes all size-one dimensions by default; pass an axis to remove only one. Expanding is how a single image becomes a batch of one before it enters a model.

Matmul, dot, cast & argmaxthe four operations that decide code questions
OperationRule / resultExam line
tf.matmul(A, B)The inner dimensions must match: [m, n] × [n, p] → [m, p].“Matmul is not element-wise multiplication.”
tf.tensordot(A, B, axes=1)Dot product; for 1-D vectors it is the scalar sum of products. For matrices, transpose B first so the inner dimensions align.“Dot contracts a shared axis.”
tf.cast(t, tf.float32)Changes the data type.“Cast before sqrt on integers.”
tf.argmax(t)Returns the index of the maximum element.“Argmax gives the position; reduce_max gives the value.”
tf.reduce_max(t)Returns the maximum value.Do not confuse it with argmax.

Argmax is how a classifier turns a probability vector into a predicted class: the label with the highest probability sits at the argmax index. tf.sqrt() expects a floating type; an integer tensor normally needs tf.cast() first. And adding a value to a tf.constant() does not mutate it in place — it creates a new tensor.

tensor_ops.py
import tensorflow as tf

a = tf.constant([[1., 2., 3.], [4., 5., 6.]])   # shape [2, 3]
b = tf.constant([[1., 2.], [3., 4.], [5., 6.]])  # shape [3, 2]
print(tf.matmul(a, b).shape)                    # [2, 2]
print(tf.argmax(a, axis=1))                     # index of max in each row
print(tf.cast(a, tf.int32))                     # dtype change
print(tf.reduce_sum(a), tf.reduce_mean(a))      # scalar reductions
الضرب والمتجهات والتحويل والأرجماكس:
tf.matmul يشترط تطابق الأبعاد الداخلية: [m, n] × [n, p] ← [m, p]. وtf.tensordot يحسب الضرب النقطي ويقلّص محوراً مشتركاً؛ وللمصفوفات اقلب B أولاً لتتطابق الأبعاد الداخلية. وtf.cast يغيّر نوع البيانات، وtf.sqrt يحتاج نوعاً عشرياً فحوّل الصحيح أولاً. وtf.argmax يعيد موقع أكبر قيمة، بينما tf.reduce_max يعيد القيمة نفسها. وإضافة قيمة إلى tf.constant لا تعدّله في مكانه بل تنشئ تنسوراً جديداً.
⌘
Reshape, transpose & aggregationssame numbers, different order

tf.reshape() changes the shape while preserving the order of values. tf.transpose() swaps axes and therefore reorders values. When output shapes match, the two can still produce different values — so “always produce the same values” is false.

Aggregation operations calculate minimum, maximum, mean and sum. tf.reduce_min() returns the minimum value, not its position; tf.argmin() returns the position. Aggregations collapse an axis unless you keep it.

reshape_transpose.py
t = tf.constant([[1, 2, 3], [4, 5, 6]])

print(tf.reshape(t, [3, 2]))     # keeps value order: [[1,2],[3,4],[5,6]]
print(tf.transpose(t))           # swaps axes:      [[1,4],[2,5],[3,6]]
print(tf.reduce_min(t), tf.reduce_max(t))
print(tf.reduce_mean(t), tf.reduce_sum(t))
print(tf.argmin(t), tf.argmax(t))  # positions, not values
إعادة التشكيل والتبديل والتجميع:
tf.reshape يغيّر الشكل مع الحفاظ على ترتيب القيم، وtf.transpose يبدّل المحاور فيعيد ترتيب القيم؛ وقد يختلفان في القيم حتى لو تطابق شكل الناتج. وعمليات التجميع تحسب الأدنى والأعلى والمتوسط والمجموع. وtf.reduce_min يعيد القيمة الدنيا لا موقعها، بينما tf.argmin يعيد الموقع. والتجميع يطوي المحور ما لم تحتفظ به.

X, y & the Sequential APIfeatures in, targets out, layers in a line

In supervised regression, X represents the features or input data and y represents the labels or target outputs. The model learns a mapping from X to y. A neural network has no single mandatory architecture: depth, width, activation and optimizer are choices.

The Sequential API builds a model by arranging layers one after another. Each layer receives the output of the previous layer. For a regression problem, the final layer usually has one unit and no activation, because the output is a continuous number.

model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(3,)),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(1)                    # regression output
])

model.compile(optimizer='adam',
              loss='mae',
              metrics=['mae'])

history = model.fit(X_train, y_train,
                    validation_split=0.2,
                    epochs=50,
                    batch_size=32)

The training set is normally the largest subset. The validation set tunes the model and compares settings during development — it can reveal whether the model needs more training. The test set is kept separate until final evaluation and must not be used repeatedly to choose settings.

One-hot, normalization & standardizationnumbers the network can compare

Neural networks require numerical inputs, so categorical variables are converted into numbers. One-hot encoding represents each category with an indicator column — three classes become [1,0,0], [0,1,0], [0,0,1]. It avoids inventing a false order between categories.

ScalingFormulaResult
Normalization(x − min) / (max − min)Usually maps values to 0–1.
Standardization(x − mean) / standard deviationMean 0, unit variance.

They are not identical. Feature scaling helps because features with very different numerical ranges become comparable. Changing from SGD to Adam changes the optimizer, not the loss function automatically. And a model should be judged by numerical metrics, not visual inspection alone.

prepare_features.py
# one-hot encoding
labels = tf.keras.utils.to_categorical([0, 1, 2], num_classes=3)

# normalization → 0..1
X_norm = (X - X.min(axis=0)) / (X.max(axis=0) - X.min(axis=0))

# standardization → mean 0, unit variance
X_std = (X - X.mean(axis=0)) / X.std(axis=0)
الترميز الأحادي والتطبيع والتقييس:
الشبكات العصبية تحتاج مدخلات رقمية، لذلك تُحوَّل المتغيرات الفئوية إلى أرقام. والترميز الأحادي يمثل كل فئة بعمود مؤشر: ثلاث فئات تصبح [1,0,0] و[0,1,0] و[0,0,1]، ويتجنب اختراع ترتيب زائف بين الفئات.
التطبيع يحوّل القيم عادةً إلى 0–1 عبر طرح الأدنى والقسمة على المدى، والتقييس يستخدم المتوسط والانحراف المعياري فيعطي متوسطاً 0 وتبايناً 1. وهما ليسا متطابقين. وتغيير SGD إلى Adam يغيّر المحسّن لا دالة الخسارة، والنموذج يُقيَّم بمقاييس رقمية لا بالنظر فقط.

Exam trapthe test set is not a tuning knob

Hadoop: storage, resources, processingHDFS + YARN + MapReduce

Hadoop is an open-source distributed computing platform for reliable, scalable, distributed processing of large datasets. It is not one program: it is a stack of three responsibilities.

ComponentResponsibilityExam line
HDFSFault-tolerant distributed storage; large files split into blocks across nodes. The NameNode maintains file-system metadata; DataNodes store the blocks.“HDFS stores and processes data in a distributed manner.”
YARNResource management and job scheduling; allocates CPU/memory to applications.“YARN is the cluster’s operating system for resources.”
MapReduceDistributed batch processing: Map filters/sorts/transforms, Reduce aggregates after mapping.“MapReduce splits large datasets and processes them in parallel.”

Replication keeps copies of blocks on multiple nodes; the default Hadoop replication factor is 3. That is why HDFS survives a disk or node failure. HDFS is optimised for large files and streaming reads, not fast random access to tiny files. The common use case for Hadoop is batch processing of large volumes, not real-time decision making.

“Three replicas is not paranoia when the rack is the size of a room.”

HDFS survives a dead disk because it never trusted a single copy.

— THE DATA JANITOR
Hadoop: تخزين وموارد ومعالجة:
Hadoop منصة حوسبة موزعة مفتوحة المصدر لمعالجة بيانات كبيرة بموثوقية وقابلية توسع. وهو ثلاث مسؤوليات: HDFS للتخزين الموزع المتحمل للأعطال، حيث يحتفظ NameNode ببيانات التعريف الوصفية ويخزن DataNode الكتل. وYARN لإدارة الموارد وجدولة المهام وتخصيص المعالج والذاكرة. وMapReduce للمعالجة الدفعية الموزعة: Map يفلتر ويرتب ويحوّل، وReduce يجمّع بعد المرحلة الأولى.
والتكرار يبقي نسخاً من الكتل على عقد متعددة، وعامل التكرار الافتراضي في Hadoop هو 3، ولهذا ينجو HDFS من فشل قرص أو عقدة. وHDFS مُحسَّن للملفات الكبيرة والقراءة المتدفقة لا للوصول العشوائي السريع للملفات الصغيرة. والاستخدام الشائع لـHadoop هو المعالجة الدفعية للأحجام الكبيرة لا القرار الفوري.

Scale mechanicssplit it, copy it, keep it close
  • Sharding / partitioning — divide data into smaller independent pieces across nodes for parallel processing.
  • Replication — keep copies on multiple nodes; enhances fault tolerance and availability.
  • Redundancy — duplicated data; improves reliability, at the cost of storage.
  • Fault tolerance — handle hardware/software failure without losing data or processing capability.
  • In-memory computing — keep data in RAM to reduce disk I/O and increase speed.
  • Cloud computing — scalability, flexibility and cost-effectiveness; elastic resources.
  • Edge computing — process data near where it is generated, reducing latency and bandwidth.

Distributed computing gives faster processing through parallel execution across multiple nodes. The trade-off is coordination, network cost and operational complexity. Replication is not compression: it buys reliability with storage, not space savings.

ميكانيكا التوسع:
التجزئة (Sharding/Partitioning) تقسم البيانات إلى أجزاء مستقلة أصغر على عقد متعددة للمعالجة المتوازية. والتكرار (Replication) يبقي نسخاً على عقد متعددة فيعزز تحمل الأعطال والتوافر. والتكرار الزائد (Redundancy) بيانات مكررة يحسّن الموثوقية مقابل مساحة تخزين. وتحمل الأعطال يعني التعامل مع فشل العتاد أو البرمجيات دون فقدان البيانات أو القدرة على المعالجة.
والحوسبة في الذاكرة تبقي البيانات في RAM لتقليل إدخال/إخراج القرص وزيادة السرعة. والسحابة توفر مرونة وتوسعاً وفعالية تكلفة. وحوسبة الحافة تعالج البيانات قرب مصدرها لتقليل التأخير والنطاق. والحوسبة الموزعة تعطي معالجة أسرع بالتنفيذ المتوازي، وثمنها التنسيق والشبكة والتعقيد التشغيلي. والتكرار ليس ضغطاً: يشتري الموثوقية بمساحة لا يوفرها.

Foundations · Big Data and the 5 Vs — س01 to س03

Big Data is data that is large, rapidly growing and diverse enough to challenge traditional processing methods; operationally, it is the analysis of datasets too large or too complex for traditional tools. Traditional RDBMSs assume structured rows and columns with a fixed schema and SQL, while a single server has fixed CPU, RAM, disk and network ceilings. Big Data adds unstructured formats, high arrival speed and scale beyond one machine, so the answer is distributed storage, parallel processing and flexible models.

keywords · large · rapidly growing · diverse · traditional methods · fixed schema · single-server limits · distributed · parallel

البيانات الضخمة كبيرة وسريعة النمو ومتنوعة إلى درجة تتحدى المعالجة التقليدية، أو عملياً مجموعات أكبر أو أعقد من أن تتعامل معها الأدوات التقليدية. وقواعد RDBMS تفترض صفوفاً وأعمدة بمخطط ثابت وSQL، والخادم الواحد له سقف معالج وذاكرة وقرص وشبكة. والحل تخزين موزع ومعالجة متوازية ونماذج مرنة.

Structured data has a predefined schema in rows and columns and is queried with SQL — for example customer records in an RDBMS or Hive. Semi-structured data carries a flexible schema in tags, keys or attributes — JSON, XML, logs or email — and is handled by document stores, NoSQL or Spark. Unstructured data has no predefined schema — text, images, video, audio and sensor streams — and needs NLP, computer vision or a data lake. Standard SQL alone cannot query raw video.

keywords · structured: fixed schema/rows/columns/SQL · semi: tags/keys/attributes/JSON · unstructured: no schema/text/images/video · NLP/computer vision

المنظّمة مخطط ثابت وصفوف وأعمدة وSQL مثل سجلات العملاء في RDBMS أو Hive. وشبه المنظّمة تحمل مخططها في الوسوم والمفاتيح مثل JSON وXML والسجلات، وتعالجها مخازن المستندات وNoSQL وSpark. وغير المنظّمة بلا مخطط مثل النصوص والصور والفيديو والصوت وتدفقات الحساسات، وتحتاج NLP والرؤية الحاسوبية أو بحيرة بيانات. وSQL وحدها لا تستعلم فيديو خاماً.

Volume is the amount of data — petabytes of clickstream. Velocity is the speed of generation and processing — millions of card swipes per second. Variety is the range of shapes — tables, JSON, video and text in one pipeline. Veracity is trustworthiness and quality — missing values, noisy sensors, duplicates. Descriptive analytics answers “What happened?” using reports, dashboards and KPIs. Diagnostic analytics answers “Why did it happen?” using root-cause analysis, drill-down and correlation. Machine learning and tensors — س06 to س07

Traditional programming provides inputs and rules and produces outputs. Machine learning provides inputs and desired outputs and discovers rules or patterns. Use ML when complex patterns are difficult to specify as rules — face recognition, demand prediction, fraud detection. Prefer a simple, reliable rule-based system when one exists: it is cheaper, explainable and deterministic. Deep learning uses multilayered neural networks and benefits from large labelled datasets and GPU/TPU compute, but its patterns are not always interpretable, it is not automatically safe when errors are unacceptable, and a changing environment can break a model trained on yesterday’s distribution.

Shape is the length of each dimension; rank is the number of dimensions; size is the total number of elements. Training and the ecosystem — س08 to س10

Create the architecture with the Sequential API, arranging layers. Compile sets the loss (measures prediction error), the optimizer (how parameters are updated) and the metrics (monitor/report performance). Fit lets the model discover patterns in the training data. Parameters such as weights and biases are learned; hyperparameters such as learning rate, epochs, batch size, number of layers and optimizer are chosen and tuned. The training set is largest; the validation set tunes and compares settings; the test set is held out until final evaluation and must not be reused for tuning. MAE averages absolute errors; MSE squares them, giving larger errors more influence. One-hot encodes categories; normalization maps to 0–1; standardization gives mean 0 and unit variance.
